A small seq2seq Transformer that rewrites astrophysics paper abstracts into
bedtime stories. Course project for a text generation class.



Input: an abstract from arXiv (astro-ph).
Output: a short bedtime story conveying the same finding.

The model is an encoder-decoder Transformer written from scratch in PyTorch
(no `nn.Transformer`). Training data is a parallel corpus of ~3.8k
(abstract, story) pairs — abstracts are real, stories were generated by
prompting Claude Haiku, then used as supervision to train our own model.
